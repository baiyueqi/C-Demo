# 二叉树分层遍历课堂研讨报告

## 1. 选题介绍

二叉树是数据结构中的基础内容，在搜索、表达式处理、层级关系描述等场景中有广泛应用。二叉树的遍历方式包括先序遍历、中序遍历、后序遍历和层序遍历，其中层序遍历要求按照从上到下、从左到右的顺序访问节点。

本次选题以二叉树的分层遍历为主题，围绕算法设计、数据结构选择、代码实现和性能分析展开。该题目具有较强的代表性，能够体现广度优先搜索思想及队列结构在树问题中的应用，适合作为课堂研讨题目。

## 2. 选题分析

本题要求输入一棵二叉树，并将其节点按照层次顺序输出。与深度优先遍历不同，分层遍历的关键在于：

1. 必须先访问完当前层所有节点，再访问下一层节点。
2. 同一层节点的访问顺序应保持从左到右。
3. 需要将每一层的结果单独保存，形成二维结果结构。
4. 需要处理空树、单节点树和非完全二叉树等不同情况。

从问题本质来看，层序遍历属于按层推进的访问过程，因此需要一种能够保证节点按进入顺序依次处理的数据结构。为此，队列是最合适的选择。

除了核心遍历逻辑，完整程序还需要解决以下实现问题：

1. 如何从输入数据构建二叉树。
2. 如何输出结构化结果。
3. 如何释放动态申请的节点内存。

因此，本题不仅是一个基础算法问题，也包含一定的程序工程实现内容。

## 3. 算法选择

本题采用广度优先搜索，即 BFS 作为主要算法，使用 `queue<TreeNode*>` 保存当前待访问节点。

选择 BFS 的原因如下：

1. BFS 按层扩展节点，天然符合题目要求。
2. 队列的先进先出特性能够保证访问顺序正确。
3. 每一轮循环处理一整层节点，逻辑清晰，便于实现和调试。
4. 算法复杂度较优，每个节点仅访问一次。

算法步骤如下：

1. 若根节点为空，直接返回空结果。
2. 将根节点加入队列。
3. 当队列不为空时，记录当前队列长度为本层节点数。
4. 依次弹出本层所有节点，并将其值保存到当前层结果中。
5. 若节点存在左孩子或右孩子，则将其加入队列。
6. 当前层遍历结束后，将该层结果加入总结果。
7. 队列为空时，遍历结束。

## 4. 代码实现

本程序使用 C++17 编写，对应代码文件为 `Algorithm/thrid/LevelOrderTraversal.cpp`。

### 4.1 数据结构设计

程序中的二叉树节点定义如下：

```cpp
struct TreeNode {
    int val;
    TreeNode* left;
    TreeNode* right;

    explicit TreeNode(int value) : val(value), left(nullptr), right(nullptr) {}
};
```

其中：

1. `val` 表示节点值。
2. `left` 指向左子节点。
3. `right` 指向右子节点。

### 4.2 核心算法实现

核心函数 `levelOrder` 负责完成分层遍历：

```cpp
vector<vector<int>> levelOrder(TreeNode* root) {
    vector<vector<int>> result;
    if (root == nullptr) {
        return result;
    }

    queue<TreeNode*> nodes;
    nodes.push(root);

    while (!nodes.empty()) {
        const size_t levelSize = nodes.size();
        vector<int> level;
        level.reserve(levelSize);

        for (size_t i = 0; i < levelSize; ++i) {
            TreeNode* current = nodes.front();
            nodes.pop();

            level.push_back(current->val);

            if (current->left != nullptr) {
                nodes.push(current->left);
            }
            if (current->right != nullptr) {
                nodes.push(current->right);
            }
        }

        result.push_back(std::move(level));
    }

    return result;
}
```

### 4.3 辅助实现

为使程序可直接运行并便于展示，本次实现还增加了以下辅助函数：

1. `buildTreeFromLevelOrder`
根据层序输入构建二叉树，支持 `null` 或 `#` 表示空节点。

2. `printLevels`
按二维数组格式输出遍历结果，便于阅读和展示。

3. `destroyTree`
遍历并释放动态申请的树节点，避免内存泄漏。

### 4.4 代码优化点

本次实现中的优化主要包括：

1. 使用 `level.reserve(levelSize)` 预先分配当前层存储空间，减少 `vector` 扩容次数。
2. 使用 `std::move(level)` 将当前层结果移动到总结果中，减少不必要拷贝。
3. 对空树情况进行提前返回，避免无效处理。
4. 补充内存释放逻辑，使示例程序更完整规范。

## 5. 实现结果

### 5.1 输入样例

```text
7

```

该输入表示的二叉树结构为：

```text
        1
      /   \
     2     3
    / \     \
   4   5     6
```

### 5.2 输出结果

```text
[
  [1],
  [2, 3],
  [4, 5, 6]
]
```

### 5.3 结果说明

1. 第一层只有根节点 `1`。
2. 第二层包含节点 `2` 和 `3`。
3. 第三层包含节点 `4`、`5` 和 `6`。
4. 输出顺序与分层遍历定义完全一致。

## 6. 性能分析

设二叉树共有 `n` 个节点。

### 6.1 时间复杂度

分层遍历中，每个节点最多执行一次入队和一次出队操作，因此遍历部分时间复杂度为：

`O(n)`

构建树时也只需线性扫描输入序列一次，因此建树复杂度同样为：

`O(n)`

综合来看，程序整体时间复杂度为：

`O(n)`

### 6.2 空间复杂度

1. 队列在最坏情况下可能存储某一整层节点，空间复杂度为 `O(n)`。
2. 结果数组需要保存全部节点值，空间复杂度为 `O(n)`。
3. 构树过程中使用节点数组辅助连接子节点，也为 `O(n)`。

因此程序整体空间复杂度为：

`O(n)`

### 6.3 性能特点

1. 对中小规模二叉树，程序能够快速完成遍历。
2. 算法逻辑稳定，不依赖递归，避免了深层树结构时的递归栈开销。
3. 适合作为基础教学实现和课程实验示例。
