# 二叉树分层遍历 PPT 设计与内容文档

## 1. 使用说明

本文件用于制作关于“二叉树分层遍历算法设计与实现”的课堂汇报 PPT。内容基于代码文件 `Algorithm/thrid/LevelOrderTraversal.cpp`，可直接用于幻灯片制作，也可在此基础上继续精简。

建议 PPT 页数控制在 8 到 10 页，汇报时长控制在 5 分钟左右。

## 2. 整体设计思路

PPT 设计建议遵循以下原则：

1. 结构清晰，按“问题提出、算法设计、代码实现、结果分析、总结提升”的顺序展开。
2. 每页信息量适中，避免整页大段文字。
3. 尽量结合树结构示意图、流程图和代码片段，增强可讲解性。
4. 重点突出 BFS 和队列在本题中的作用。

版式建议：

1. 标题统一使用简洁风格。
2. 正文字体尽量统一。
3. 代码页和结果页可采用左右分栏布局。
4. 适当使用蓝色或深色作为主色，保持教学汇报风格。

2. 子节点必须在父节点之后处理。

### 第5页：算法选择

页面标题：算法选择

建议展示要点：

1. 采用广度优先搜索 BFS。
2. 使用队列保存待访问节点。
3. 每次从队列中取出当前层所有节点。
4. 再将下一层节点依次加入队列。

可直接放入的算法步骤：

1. 根节点入队。
2. 记录当前队列大小作为本层节点数。
3. 依次访问本层节点并保存结果。
4. 将左右孩子加入队列。
5. 本层结束后保存当前层结果。
6. 队列为空时结束遍历。

讲解提示：

突出 BFS 与队列的天然匹配关系。

### 第6页：核心代码实现

页面标题：核心代码实现

建议放置代码片段：

```cpp
while (!nodes.empty()) {
    const size_t levelSize = nodes.size();
    vector<int> level;
    level.reserve(levelSize);

    for (size_t i = 0; i < levelSize; ++i) {
        TreeNode* current = nodes.front();
        nodes.pop();

        level.push_back(current->val);

        if (current->left != nullptr) nodes.push(current->left);
        if (current->right != nullptr) nodes.push(current->right);
    }

    result.push_back(std::move(level));
}
```

讲解提示：

1. `levelSize` 用于限定当前层范围。
2. `reserve` 是减少扩容次数的小优化。
3. `std::move` 用于减少结果写入时的额外拷贝。

## 5. 答辩准备建议

汇报时可能被问到的问题包括：

1. 为什么本题适合使用队列。
2. 为什么选择 BFS 而不是 DFS。
3. 如何判断每一层的节点范围。
4. 程序的时间复杂度和空间复杂度如何得到。
5. 如果改成之字形遍历，应如何修改。

可参考回答方向：

1. 队列先进先出，适合维护层次访问顺序。
2. BFS 按层推进，天然符合题意。
3. 通过记录每轮循环开始时的队列大小，可以确定当前层节点数。
4. 每个节点仅处理一次，因此时间复杂度为 `O(n)`。
5. 之字形遍历可以通过反转奇数层结果，或改用双端队列实现。
