# WTA 武器-目标分配系统设计文档

## 1. 设计目标

本设计围绕武器-目标分配问题（Weapon-Target Assignment，WTA）展开。系统需要在给定武器数量、目标数量、目标威胁值和武器毁伤概率的条件下，计算合理的武器分配方案，使目标剩余威胁尽可能小，并通过实验和动画展示算法效果。

最终需要完成四项内容：

1. 建立 WTA 数学模型；
2. 实现两种分配算法；
3. 使用不同规模数据进行实验对比；
4. 展示武器打击目标的动态过程。

推荐最终路线：

```text
数据生成 + 数学模型 + 贪心算法 + 遗传算法 + 实验分析 + Qt/Unity 可视化
```

## 4. 数学模型设计

### 4.1 集合定义

武器集合：

```text
W = {w_1, w_2, ..., w_m}
```

目标集合：

```text
T = {t_1, t_2, ..., t_n}
```

本课题数据中：

```text
m = n
```

### 4.2 决策变量

```text
x_ij = 1：武器 w_i 分配给目标 t_j
x_ij = 0：武器 w_i 不分配给目标 t_j
```

### 4.3 目标函数

采用“最小化目标剩余威胁”作为主目标。

如果目标 `t_j` 被多个武器攻击，则其生存概率为：

```text
s_j = product(i=1..m)(1 - p_ij)^x_ij
```

目标 `t_j` 的剩余威胁为：

```text
remainingThreat_j = v_j * s_j
```

整体目标函数为：

```text
min f = sum(j=1..n) v_j * product(i=1..m)(1 - p_ij)^x_ij
```

为了展示算法收益，同时计算总毁伤收益：

```text
d = sum(j=1..n) v_j - f
```

其中：

- `f`：总剩余威胁；
- `d`：总毁伤收益。

### 4.4 约束条件

每个武器只能分配给一个目标：

```text
sum(j=1..n) x_ij = 1
```

每个目标可以被多个武器攻击：

```text
sum(i=1..m) x_ij >= 0
```

变量取值：

```text
x_ij ∈ {0, 1}
```

## 6. 核心数据结构设计

### 6.1 目标数据

```cpp
struct Target {
    int id;
    double threatValue;
};
```

### 6.2 WTA 实例

```cpp
struct WtaInstance {
    int weaponCount;
    int targetCount;
    std::vector<Target> targets;
    std::vector<std::vector<double>> killProbability;
};
```

### 6.3 分配方案

使用一维数组表示分配方案：

```cpp
std::vector<int> assignment;
```

约定：

```cpp
assignment[weaponIndex] = targetIndex;
```

含义是：

```text
武器 weaponIndex 分配给目标 targetIndex
```

例如：

```text
assignment = [2, 0, 3, 1]
```

表示：

```text
武器0 -> 目标2
武器1 -> 目标0
武器2 -> 目标3
武器3 -> 目标1
```

### 6.4 评价结果

```cpp
struct EvaluationResult {
    double remainingThreat;
    double damageValue;
};
```

### 6.5 算法结果

```cpp
struct SolverResult {
    std::string solverName;
    std::vector<int> assignment;
    EvaluationResult evaluation;
    double runtimeMs;
    std::vector<double> bestFitnessHistory;
    std::vector<double> averageFitnessHistory;
};
```

## 7. 评价函数设计

评价函数是整个系统的核心，`GreedySolver` 和 `GeneticSolver` 必须使用同一个评价函数。

函数命名：

```cpp
EvaluationResult evaluateAssignment(
    const WtaInstance& instance,
    const std::vector<int>& assignment
);
```

输入：

```text
WtaInstance instance
std::vector<int> assignment
```

输出：

```text
EvaluationResult
```

计算步骤：

1. 初始化每个目标的生存概率 `survivalProbability[j] = 1.0`；
2. 遍历每个武器 `weaponIndex`；
3. 找到该武器分配的目标：

```cpp
int targetIndex = assignment[weaponIndex];
```

4. 更新目标 `targetIndex` 的生存概率：

```cpp
survivalProbability[targetIndex] *=
    (1.0 - instance.killProbability[weaponIndex][targetIndex]);
```

5. 遍历所有目标，计算 `remainingThreat`：

```cpp
remainingThreat +=
    instance.targets[targetIndex].threatValue *
    survivalProbability[targetIndex];
```

6. 计算 `damageValue`：

```cpp
damageValue = totalThreat - remainingThreat;
```

## 8. 算法一：GreedySolver

### 8.1 设计思想

`GreedySolver` 每次选择当前收益最大的武器-目标组合。

当前目标 `targetIndex` 的生存概率为 `survivalProbability[targetIndex]`。若武器 `weaponIndex` 攻击该目标，带来的边际收益为：

```text
gain(weaponIndex, targetIndex)
    = threatValue[targetIndex]
    * survivalProbability[targetIndex]
    * killProbability[weaponIndex][targetIndex]
```

每轮选择 `gain(weaponIndex, targetIndex)` 最大的组合。

### 8.2 实现步骤

1. 初始化 `assignment`，所有值设置为 `-1`；
2. 初始化 `weaponAssigned[weaponIndex] = false`；
3. 初始化 `survivalProbability[targetIndex] = 1.0`；
4. 在所有未分配武器和所有目标之间计算 `gain`；
5. 找到收益最大的组合：

```cpp
bestWeaponIndex
bestTargetIndex
```

6. 设置分配结果：

```cpp
assignment[bestWeaponIndex] = bestTargetIndex;
```

7. 更新目标生存概率：

```cpp
survivalProbability[bestTargetIndex] *=
    (1.0 - killProbability[bestWeaponIndex][bestTargetIndex]);
```

8. 标记该武器已经分配：

```cpp
weaponAssigned[bestWeaponIndex] = true;
```

9. 重复步骤 4 到步骤 8，直到所有武器分配完成；
10. 调用 `evaluateAssignment()` 计算最终结果。

### 8.3 优缺点

优点：

- 实现简单；
- 速度快；
- 可作为实验基准。

缺点：

- 只关注当前最优；
- 容易陷入局部最优；
- 分配结果不一定是全局最优。

## 9. 算法二：GeneticSolver

### 9.1 设计思想

`GeneticSolver` 维护一组候选分配方案，通过选择、交叉、变异不断产生新方案，并保留较优个体。它适合 WTA 这类解空间很大的组合优化问题。

### 9.2 染色体编码

染色体使用一维整数数组：

```cpp
std::vector<int> chromosome;
```

约定：

```cpp
chromosome[weaponIndex] = targetIndex;
```

表示：

```text
武器 weaponIndex 分配给目标 targetIndex
```

例如：

```text
chromosome = [3, 1, 0, 2]
```

表示：

```text
武器0 -> 目标3
武器1 -> 目标1
武器2 -> 目标0
武器3 -> 目标2
```

这种编码天然满足“每个武器只能分配给一个目标”的约束。

### 9.3 适应度函数

推荐直接使用 `damageValue` 作为适应度：

```text
fitness = damageValue
```

`damageValue` 越大，个体越优秀。

### 9.4 遗传操作

选择操作使用锦标赛选择，函数命名建议为：

```cpp
Individual tournamentSelect(const std::vector<Individual>& population);
```

交叉操作使用单点交叉或两点交叉，函数命名建议为：

```cpp
std::pair<Individual, Individual> crossover(
    const Individual& parentA,
    const Individual& parentB
);
```

变异操作随机改变某个武器分配的目标，函数命名建议为：

```cpp
void mutate(Individual& individual);
```

精英保留操作每一代保留当前最优个体，防止最优解在交叉和变异中丢失。

### 9.5 推荐参数

| 参数名称 | 代码名称 | 推荐值 |
| --- | --- | ---: |
| 种群规模 | `populationSize` | 50 |
| 最大迭代代数 | `maxGeneration` | 300 |
| 交叉概率 | `crossoverRate` | 0.8 |
| 变异概率 | `mutationRate` | 0.03 |
| 锦标赛规模 | `tournamentSize` | 3 |
| 精英数量 | `eliteCount` | 1 |

### 9.6 实现步骤

1. 随机生成初始种群 `population`；
2. 调用 `evaluateAssignment()` 计算每个个体的 `damageValue`；
3. 记录当前最优个体 `bestIndividual`；
4. 使用 `tournamentSelect()` 生成父代；
5. 按 `crossoverRate` 执行交叉；
6. 按 `mutationRate` 执行变异；
7. 将精英个体放入下一代；
8. 更新种群；
9. 记录当前代最优适应度到 `bestFitnessHistory`；
10. 记录当前代平均适应度到 `averageFitnessHistory`；
11. 重复步骤 2 到步骤 10，直到达到 `maxGeneration`；
12. 输出最优分配方案、`remainingThreat`、`damageValue` 和收敛曲线。

## 11. 可视化设计

### 11.1 推荐方案

优先推荐使用 Qt 做二维动画演示。

原因：

- 开发周期短；
- 二维场景足够表达分配关系；
- 容易展示轨迹、命中和结果；
- 比 Unity3D 更适合快速完成课程设计。

如果课程要求必须使用 Unity3D，则算法部分仍然用 C++ 生成结果，再导出 JSON 给 Unity 读取。

### 11.2 界面命名

界面组件建议统一命名如下：

| 界面元素 | 代码名称 |
| --- | --- |
| 武器节点 | `WeaponItem` |
| 目标节点 | `TargetItem` |
| 导弹节点 | `MissileItem` |
| 轨迹线 | `TrajectoryItem` |
| 分配列表 | `AssignmentPanel` |
| 结果面板 | `ResultPanel` |
| 算法选择框 | `SolverSelector` |
| 动画控制器 | `AnimationController` |

### 11.3 界面内容

界面至少包含：

1. 武器节点 `WeaponItem`；
2. 目标节点 `TargetItem`；
3. 分配结果列表 `AssignmentPanel`；
4. 导弹飞行轨迹 `TrajectoryItem`；
5. 命中动画；
6. 剩余威胁 `remainingThreat`；
7. 毁伤收益 `damageValue`；
8. 算法选择框 `SolverSelector`。

### 11.4 动画流程

1. 加载一组 `WtaInstance` 数据；
2. 选择求解器 `GreedySolver` 或 `GeneticSolver`；
3. 运行求解器得到 `SolverResult`；
4. 在界面上绘制 `WeaponItem` 和 `TargetItem`；
5. 在 `AssignmentPanel` 中显示 `assignment`；
6. 根据分配关系生成 `TrajectoryItem`；
7. 使用 `AnimationController` 让 `MissileItem` 沿轨迹移动；
8. 导弹到达目标后播放命中效果；
9. 更新目标状态；
10. 在 `ResultPanel` 中展示最终统计结果。

### 第 2 步：实现 DataGenerator

需要完成：

1. 输入实例规模 `weaponCount` 和 `targetCount`；
2. 生成目标威胁值 `threatValue`；
3. 生成毁伤概率矩阵 `killProbability`；
4. 保存为 CSV 或 JSON；
5. 固定随机种子 `randomSeed`，保证结果可复现。

### 第 3 步：实现 Evaluator

需要完成：

1. 输入分配方案 `assignment`；
2. 计算每个目标的最终生存概率 `survivalProbability`；
3. 计算总剩余威胁 `remainingThreat`；
4. 计算总毁伤收益 `damageValue`；
5. 返回 `EvaluationResult`。

该步骤必须先做，因为两个算法都依赖它。

### 第 4 步：实现 GreedySolver

需要完成：

1. 根据边际收益 `gain` 选择武器-目标组合；
2. 每轮固定一个武器分配；
3. 更新目标生存概率 `survivalProbability`；
4. 输出完整分配方案 `assignment`；
5. 调用 `evaluateAssignment()` 验证结果。

### 第 5 步：实现 GeneticSolver

需要完成：

1. 设计染色体 `chromosome`；
2. 初始化种群 `population`；
3. 计算适应度 `fitness`；
4. 实现选择 `tournamentSelect()`；
5. 实现交叉 `crossover()`；
6. 实现变异 `mutate()`；
7. 实现精英保留；
8. 输出最优结果和收敛数据。

### 第 6 步：运行实验

需要完成：

1. 运行小、中、大、超大规模数据；
2. 记录 `GreedySolver` 结果；
3. `GeneticSolver` 每组运行 10 次；
4. 汇总结果表格；
5. 绘制 `GeneticSolver` 收敛曲线；
6. 分析两种算法的差异。

### 第 7 步：实现可视化

需要完成：

1. 读取算法输出 `SolverResult`；
2. 绘制 `WeaponItem` 和 `TargetItem`；

4. 播放导弹飞行动画；
5. 播放命中效果；
6. 显示最终 `damageValue` 和 `remainingThreat`。

### 第 8 步：完成报告

| 贪心算法 | `GreedySolver` 能输出合法 `assignment` |
| 遗传算法 | `GeneticSolver` 能输出更优或接近更优的方案，并有收敛过程 |
| 实验分析 | 有结果表、运行时间和稳定性分析 |
| 可视化 | 能展示分配关系、飞行轨迹和命中效果 |
| 报告 | 能说明设计思路、实现步骤和实验结论 |

## 14. 推荐完成顺序

最稳妥的完成顺序是：

```text
数学模型
DataGenerator
Evaluator
GreedySolver
GeneticSolver
ExperimentRunner
Visualizer
课程设计报告
```

核心原因是：`Evaluator` 是算法比较的统一标准，必须先完成；`GreedySolver` 实现简单，可以作为基准；`GeneticSolver` 负责提升结果质量；`Visualizer` 依赖算法输出，应放在最后实现。

## 15. 后续可改进方向

如果基础功能完成后还有时间，可以继续扩展：

1. 加入武器攻击代价 `attackCost`；
2. 加入目标优先级 `targetPriority`；
3. 加入距离或射程约束 `rangeLimit`；
4. 加入多类型武器 `weaponType`；
5. 使用模拟退火、蚁群算法或粒子群算法进行对比；
6. 将实验结果自动导出为图表。
