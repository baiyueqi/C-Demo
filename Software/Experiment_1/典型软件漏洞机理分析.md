## 三、实验基本原理

### 缓冲区溢出（栈溢出）漏洞原理

程序在栈空间申请固定长度字符缓冲区，未对用户输入长度进行边界合法性校验，使用 `strcpy`、无限制 `scanf` 等不安全函数。超长输入依次覆盖缓冲区、栈局部变量、栈基址 EBP、函数返回地址，破坏栈帧结构，造成程序崩溃、执行流程异常、权限非法篡改。

### SQL 注入漏洞原理

后端业务程序直接拼接用户可控输入构造 SQL 查询语句，未进行语法隔离与参数预处理。攻击者利用单引号闭合原有 SQL 语句结构，构造永真查询条件、注释截断后续语句，实现身份绕过、未授权登录、数据库敏感信息泄露。

## （三）漏洞源代码（Python）

```python
import sqlite3

DB_NAME = 'user_db.db'


def login(username, password):
    sql = "SELECT * FROM user_info WHERE username='" + username + "' AND password='" + password + "'"
    print("执行SQL语句：", sql)

    try:
        conn = sqlite3.connect(DB_NAME)
        cursor = conn.cursor()
        cursor.execute(sql)
        result = cursor.fetchone()
        return result
    except Exception as e:
        print("数据库异常：", e)
        return None
    finally:
        if 'conn' in locals():
            conn.close()


def init_database():
    try:
        conn = sqlite3.connect(DB_NAME)
        cursor = conn.cursor()
        cursor.execute('''CREATE TABLE IF NOT EXISTS user_info
                        (username TEXT PRIMARY KEY, password TEXT, role TEXT)''')

        # 用户密码存储
        cursor.execute("INSERT OR IGNORE INTO user_info VALUES ('admin','Admin@2026','super_admin')")
        cursor.execute("INSERT OR IGNORE INTO user_info VALUES ('user1','123456','normal_user')")

        conn.commit()
    except Exception as e:
        print("初始化失败：", e)
    finally:
        if 'conn' in locals():
            conn.close()


if __name__ == '__main__':
    init_database()
    print("===== 后台用户登录系统 =====")
    while True:
        user = input("请输入用户名：").strip()
        if user == 'exit':
            break

        pwd = input("请输入密码：").strip()

        # 空值校验
        if not user or not pwd:
            print("用户名或密码不能为空！")
            continue

        info = login(user, pwd)
        if info is not None:
            print("登录成功！欢迎进入系统后台")
            print("用户信息：", info)
            break
        else:
            print("用户名或密码错误，登录失败")
        print()
```

## 综合防护方案

1. 全程使用参数化预编译查询，严格禁止字符串拼接 SQL 语句。
2. 数据库业务账户遵循最小权限分配原则。
3. 过滤单引号、逻辑运算符、注释符等高危特殊字符。
4. 关闭数据库详细错误回显，避免语句结构泄露。
5. 用户密码采用加盐哈希加密存储，禁止明文保存敏感信息。
