# 《软件安全实验》实验指导书

**实验项目：软件权益保护**

**实验名称：软件保护技术**

**实验环境：**

- 操作系统：Windows 10/11

- 开发环境：Visual Studio 2019及以后版本

- 分析工具：UPX 5.1.1，Detect-It-Easy

## 实验目的

1. 理解软件权益保护的基本目标：授权验证、防篡改、数据加密、防逆向分析。

2. 掌握控制台程序下序列号校验、文件自校验、字符串加密的实现方法。

3. 掌握 UPX 加壳工具的使用，实现 EXE 压缩与保护。

4. 完成从编码、编译、加壳到测试的完整流程，形成可直接部署的软件保护方案。

## 实验原理

1. **序列号授权**：对用户名字符串做哈希运算，生成固定格式序列号，运行时比对实现授权控制。

2. **完整性校验**：程序读需要保护的关键数据，计算校验和；文件被修改则校验不通过。

3. **异或加密**：轻量对称加密，用于隐藏版权信息、密钥等敏感信息，避免被直接查看。

4. **UPX 加壳**：对 PE 文件进行压缩与段保护，增加逆向、修改、脱壳难度，同时减小体积。

### 任务一：序列号授权验证

**功能**：输入用户名与序列号，校验是否合法。

```c
#include <stdio.h>
#include <string.h>
unsigned int hash_str(const char* s)
{
    unsigned int h = 0;
    while (*s) {
        h = h * 131 + (*s++);
    }
    return h;
}
void make_serial(const char* name, char* out)
{
    unsigned int h = hash_str(name);
    sprintf(out, "%04X-%04X", (h >> 16) & 0xFFFF, h & 0xFFFF);
}
int check_serial(const char* name, const char* serial)
{
    char gen[32] = { 0 };
    make_serial(name, gen);
    return _stricmp(serial, gen) == 0;
}
int main()
{
    char name[64], serial[32];
    printf("UserName: ");
    scanf("%s", name);
    printf("Serial: ");
    scanf("%s", serial);
    if (check_serial(name, serial)) {
        printf("[OK] 授权成功\n");
    } else {
        printf("[ERROR] 无效序列号\n");
    }
    return 0;
}
```

### 任务二：EXE 完整性自校验

**功能**：防止程序被篡改，如修改、破解、打补丁等。

**示例：**C语言项目实现了一个针对EPO（Entry Point Obfuscation，入口点混淆）后关键数据区域（1KB）的完整性保护机制，主要包含以下核心功能：

1. **受保护区域模拟**：通过全局数组 protected_data 模拟嵌入式系统中需要重点保护的1KB关键数据段（如配置参数、密钥片段或解密后的代码段），确保校验目标明确。

2. **SHA-256 指纹校验**：集成简化的哈希计算逻辑，对受保护区域进行实时摘要计算，利用哈希的雪崩效应确保任何单比特修改都能被检测到。

3. **抗侧信道比对**：采用 secure_memcmp 恒定时间比较算法，逐字节异或累加验证当前哈希与预置信任哈希，有效防止攻击者通过测量比对耗时来推测哈希匹配进度。

```c
#include <stdio.h>
#include <stdlib.h>
#include <string.h>
#include <stdint.h>
// 定义受保护区域的大小 (1KB)
#define PROTECTED_REGION_SIZE 1024
// SHA-256 哈希长度
#define HASH_LEN 32
// 模拟的受保护数据区域
// 这里为了演示，我们使用一个全局数组来模拟这1KB的关键数据
static uint8_t protected_data[PROTECTED_REGION_SIZE];
// 预置的正确SHA-256哈希值 (在实际应用中，这个值应在编译后计算并硬编码，或存储在OTP/安全区域)
// 这里初始化为全0，将在程序启动时根据初始化的protected_data动态计算并“固化”用于演示
static uint8_t trusted_hash[HASH_LEN];
// 简化的SHA-256实现占位符
// 注意：生产环境请使用经过验证的库或硬件加速模块
void simple_sha256(const uint8_t *data, size_t len, uint8_t *hash) {
    // 这是一个极其简化的伪哈希，仅用于演示逻辑流程，不具备安全性
    // 真实实现应包含复杂的消息填充、轮函数和状态压缩
    memset(hash, 0, HASH_LEN);
    for (size_t i = 0; i < len; i++) {
        hash[i % HASH_LEN] ^= data[i];
        hash[i % HASH_LEN] = (hash[i % HASH_LEN] << 1) | (hash[i % HASH_LEN] >> 7);
    }
    // 简单的混淆
    for (int i = 0; i < HASH_LEN; i++) {
        hash[i] = (hash[i] * 31) ^ 0xAA;
    }
}
// 恒定时间比较，防止时序侧信道攻击
int secure_memcmp(const uint8_t *a, const uint8_t *b, size_t len) {
    volatile uint8_t result = 0;
    for (size_t i = 0; i < len; i++) {
        result |= a[i] ^ b[i];
    }
    return (result == 0) ? 1 : 0;
}
// 初始化受保护区域的数据 (模拟EPO后的初始状态)
void init_protected_region() {
    // 填充一些示例数据
    for (int i = 0; i < PROTECTED_REGION_SIZE; i++) {
        protected_data[i] = (uint8_t)(i % 256);
    }
    // 计算初始的信任哈希
    simple_sha256(protected_data, PROTECTED_REGION_SIZE, trusted_hash);
    printf("[Info] Protected region initialized. Trusted hash calculated.\n");
}
// 核心校验函数
int verify_epo_region() {
    uint8_t current_hash[HASH_LEN];
    // 1. 计算当前受保护区域的哈希
    simple_sha256(protected_data, PROTECTED_REGION_SIZE, current_hash);
    // 2. 与信任哈希进行恒定时间比对
    if (secure_memcmp(current_hash, trusted_hash, HASH_LEN)) {
        return 1; // 校验通过
    }
    else {
        return 0; // 校验失败
    }
}
// 模拟篡改行为
void tamper_with_data() {
    printf("\n[Action] Tampering with the first byte of protected data...\n");
    protected_data[0] ^= 0xFF; // 翻转第一个字节
}
// 恢复数据 (用于演示修复或重新校准)
void restore_data() {
    printf("\n[Action] Restoring original data...\n");
    for (int i = 0; i < PROTECTED_REGION_SIZE; i++) {
        protected_data[i] = (uint8_t)(i % 256);
    }
}
int main() {
    printf("=== EPO Protected Region Integrity Check ===\n");
    // 1. 初始化
    init_protected_region();
    // 2. 首次校验 (应通过)
    printf("\n[Test 1] Initial Verification:\n");
    if (verify_epo_region()) {
        printf("[PASS] Integrity check passed. Data is secure.\n");
    }
    else {
        printf("[FAIL] Integrity check failed! Immediate halt required.\n");
        return 1;
    }
    // 3. 模拟篡改
    tamper_with_data();
    // 4. 二次校验 (应失败)
    printf("\n[Test 2] Post-Tampering Verification:\n");
    if (verify_epo_region()) {
        printf("[PASS] Integrity check passed. (Unexpected!)\n");
    }
    else {
        printf("[ALERT] Integrity check FAILED! Tampering detected.\n");
        printf("[Security] Triggering safe mode or system reset...\n");
    }
    // 5. 恢复后校验 (应通过)
    restore_data();
    printf("\n[Test 3] Post-Restoration Verification:\n");
    if (verify_epo_region()) {
        printf("[PASS] Integrity check passed. System recovered.\n");
    }
    else {
        printf("[FAIL] Integrity check failed even after restoration.\n");
    }
    return 0;
}
```

### 任务三：敏感信息保护

**功能**：防止静态反编译直接获取明文信息

- 软件中不存储明文敏感信息如版权，只存储**加密后的密文**

- 运行时解密，防止静态分析直接看到敏感信息

```c
#include <stdio.h>#include <string.h>
// 加密/解密密钥（自定义密钥，可修改）#define XOR_KEY 0x7B
/**
 * @brief 异或加密/解密函数（加密解密同一个函数）
 * @param str 待处理的字符串
 * @param key 异或密钥
 */
void xor_encrypt_decrypt(char *str, char key) {
    // 遍历字符串直到结束符
    while (*str != '\0') {
        *str ^= key;  // 每个字符与密钥异或
        str++;
}
}
int main() {
    // ===================== 重要 =====================
    // 这里存储的是【加密后的版权密文】，不是明文！
    // 明文版权：Copyright (c) 2025 Software Protection Lab
    // =================================================
    char copyright[] = {0x1B,0x28,0x3F,0x2E,0x32,0x3B,0x2E,0x3D,0x22,0x1B,0x2E,0x2B,0x1B,0x35,0x32,0x34,0x35,0x1B,0x3B,0x34,0x2C,0x36,0x30,0x3B,0x2E,0x3D,0x22,0x1B,0x2C,0x2A,0x26,0x1B,0x30,0x3B,0x3C,0x2E,0x2A,0x3D,0x2E,0x34,0x31,0x00};
    printf("===== 软件版权信息解密输出 =====\n");
    printf("解密前(密文)：%s\n", copyright);
    // 执行解密（异或密钥还原明文）
    xor_encrypt_decrypt(copyright, XOR_KEY);
    // 输出正确版权信息
    printf("解密后(明文)：%s\n", copyright);
    printf("================================\n");
return 0;
}
```

**代码说明：**

- **密钥定义**#define XOR_KEY 0x7B 是自定义密钥，你可以改成任意十六进制 / 字符（如 0x3F、'A'）

- **加密 / 解密函数**xor_encrypt_decrypt 函数：对字符串每个字符做异或运算

加密：明文 ^ 密钥 → 密文

解密：密文 ^ 密钥 → 明文

- **版权存储**copyright 数组是**加密后的密文**，静态看是乱码，无法直接识别版权信息运行解密后才会输出：

### 任务四：EXE 加壳

- **什么是加壳？**

把原有 EXE 程序当成数据，打包压缩 / 加密，外层套一层壳程序，增加静态分析、逆向、篡改难度。

运行流程：运行 EXE → 先执行**壳代码** → 壳解密原程序 → 释放原程序内存 → 跳转执行原程序

静态查看：资源管理器、反编译工具只能看到**壳**，看不到原程序代码、字符串

- **壳分类**

压缩壳：UPX、ASPack、NPack（体积压缩，易脱壳）

加密壳：VMProtect、Themida、WinLicense（强加密、虚拟机指令，商业软件常用）

- **脱壳：将加壳程序还原为原始未加壳 EXE，逆向分析常用。**
