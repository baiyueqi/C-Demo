五层原理
HTTP/HTTPS 请求如何被捕获

封装看发送，解封装看抓包

应用层浏览器产生 HTTP 请求；HTTPS 场景下内容经 TLS 加密。
传输层TCP 面向连接、可靠、有序；UDP 无连接、开销低。程序同时解析 TCP/UDP 端口和 TCP flags。
网络层IPv4 头部包含源/目的 IP、TTL、协议号；路由器按目的 IP 转发，TTL 每跳递减。
链路层Ethernet 使用 MAC 在同一链路转发；ARP 用 IP 查询下一跳 MAC，MAC 不跨路由直达。
Socket 关系Socket 是应用使用协议栈的接口；本项目实时抓包使用 AF_PACKET 从链路层捕获帧。

总结
完成度与答辩要点

完成了从抓包到分类报警的主流程

一句话总结 系统把真实网络包解析成五元组流，再把流转换成特征，用规则和 KNN 输出类别、置信度和攻击报警。
当前存在的问题 实时抓包依赖 root 或 CAP_NET_RAW 权限；规则报警可能误报；KNN 训练类别较少，未知流量会归入最接近的已知类。
