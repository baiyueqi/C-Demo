第 1 章 引言

本项目实现一个网络流量分类器原型，覆盖抓包读取、协议解析、五元组聚合、特征提取、机器学习分类、攻击检测与报告验证。

选题目标

开发一个能够捕获或读取网络数据包的网络嗅探器，从五层协议头部提取关键字段，训练简单分类器并输出当前流量类别及置信度。

开发环境

Python 3、Wireshark、Linux / Nix 开发环境。系统不依赖第三方 Python 包，KNN 模型和实时抓包入口均使用标准库实现。

第 2 章 系统设计

系统采用“输入抓包数据、解析协议字段、聚合网络流、提取特征、分类与报警、输出 CSV”的流水线结构。

→
RawPacket / pcapng

协议解析
→
五元组流
→
特征提取
→
规则 / KNN / ALERT

抓包读取

pcap_reader.py 支持 pcap 和常见 pcapng；live_capture.py 支持 Linux 网卡实时抓包。

协议解析

parser.py 解析 Ethernet、VLAN、IPv4、TCP、UDP、ICMP，并生成统一的 PacketRecord。

分类输出

classifier.py 负责规则分类和攻击报警；ml.py 负责 KNN 训练和预测。

核心命令

python -m traffic_classifier samples/web.pcapng --csv output/web_features.csv
python -m traffic_classifier.train output/dns_features.csv output/icmp_features.csv output/web_features.csv --model models/knn_model.json
python -m traffic_classifier.predict samples/web.pcapng --model models/knn_model.json
python -m traffic_classifier.predict samples/live_100.pcapng --model models/knn_model.json --limit 10
python -m traffic_classifier.live_capture -i eth0 --count 100 --model models/knn_model.json

第 3 章 五层体系结构原理分析与验证

HTTP/HTTPS 请求从浏览器产生后，逐层添加头部，最终被网卡捕获为链路层帧；程序再按相反方向解析头部并提取特征。

应用层

浏览器生成 HTTP 请求；HTTPS 场景下请求会经 TLS 加密。

传输层

TCP 添加源端口、目的端口、序号、确认号、窗口、flags 和校验和。

网络层

IPv4 添加源 IP、目的 IP、TTL、协议号、总长度等字段。

数据链路层

Ethernet 添加源 MAC、目的 MAC 和以太网类型，例如 0x0800 表示 IPv4。

物理层

Wi-Fi 网卡把帧转换为无线信号传输；抓包程序在网卡处捕获数据帧。

第 4 章 AI 集成实现

系统同时支持可解释规则分类和 KNN 机器学习分类。KNN 使用 CSV 标签样本训练，保存模型后可对新 pcap 文件预测类别和置信度。

KNN 模型

训练样本 342 条，类别包括 DNS、ICMP、Web。Port_Scan 合成样本用于攻击报警和误报分析，不加入普通 KNN 模型，避免把正常流量误判成端口扫描。

攻击报警

规则模块检测 SYN_Flood、TCP_Probe、Port_Scan。检测到攻击时终端输出中加入 ALERT 标识。

分类规则与模型输出

DNS  -> ML=DNS  confidence=1.00
ICMP -> ML=ICMP confidence=1.00
Web  -> ML=Web  confidence=1.00

live_100.pcapng -> Web=15, DNS=4

ALERT Port_Scan confidence=0.80 packets=1 bytes=40

误报分析

构造样本 false_positive_port_scan.pcap 模拟正常客户端短时间连接同一服务器多个端口 8001 到 8005。系统会按“同一源目的对访问多个端口”的规则报警为 Port_Scan，说明规则检测容易受业务场景影响，后续可加入时间窗口、连接成功率和白名单降低误报。
