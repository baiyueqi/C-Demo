# 实验二操作文档

本实验包含三个程序：

- `myls`：自定义 `ls` 命令
- `reverse`：文本逆序输出
- `fs_auditor`：文件系统审计工具

## 1. 项目目录结构

```text
Linux/work_2/
├── Makefile
├── include/
│   ├── fs_auditor.h
│   ├── myls.h
│   ├── report.h
│   ├── reverse.h
│   └── thread_pool.h
├── src/
│   ├── fs_auditor.cpp
│   ├── myls.cpp
│   ├── report.cpp
│   ├── reverse.cpp
│   └── thread_pool.cpp
├── main/
│   ├── main.cpp
│   ├── myls_main.cpp
│   └── reverse_main.cpp
└── 实验(2).md
```

## 2. 编译程序

进入项目目录：

```bash
cd /home/nixos/workspace/C-Demo/Linux/work_2
```

编译所有程序：

```bash
make
```

也可以单独编译：

```bash
make myls
make reverse
make fs_auditor
```

清理生成的可执行文件：

```bash
make clean
```

### 2.1 Makefile 的作用

`Makefile` 把三个程序需要的多文件编译命令封装起来，避免每次手动输入长命令。

执行：

```bash
make -n
```

可以看到它实际会运行：

```text
clang++ -std=c++17 -pthread main/main.cpp src/fs_auditor.cpp src/thread_pool.cpp src/report.cpp -o fs_auditor
clang++ -std=c++17 main/myls_main.cpp src/myls.cpp -o myls
clang++ -std=c++17 main/reverse_main.cpp src/reverse.cpp -o reverse
```

因此，没有 `Makefile` 时，就需要手动执行这三条 `clang++` 命令。

## 3. myls 使用方法

### 3.1 基本用法

```bash
./myls
```

列出指定目录：

```bash
./myls /path/to/directory
```

### 3.2 参数说明

| 参数 | 作用 |
| --- | --- |
| `-a` | 显示隐藏文件 |
| `-l` | 使用长格式显示 |
| `-R` | 递归列出子目录 |
| `-i` | 显示 inode 号 |

参数可以组合使用，例如：

```bash
./myls -a -l -R -i .
```

### 3.3 示例

长格式列出当前目录：

```bash
./myls -l
```

递归显示隐藏文件：

```bash
./myls -a -R /home/nixos/workspace/C-Demo/Linux/work_2
```

### 3.4 实现说明

| 功能 | 对应文件 |
| --- | --- |
| 参数解析 | `main/myls_main.cpp` |
| 目录遍历与不同输出方式 | `src/myls.cpp` |
| 参数结构定义 | `include/myls.h` |

`-l`、`-i`、默认文件名输出以及 `-R` 递归输出在 `list_dir()` 中处理，满足实验要求中“至少三种参数，对应三种不同输出方式”的要求。

## 4. reverse 使用方法

### 4.1 参数说明

| 参数 | 作用 |
| --- | --- |
| `-l` | 反转整行顺序 |
| `-w` | 反转每行中的单词顺序 |
| `-lw` 或 `-wl` | 同时反转整行顺序和单词顺序 |

### 4.2 示例

按单词逆序：

```bash
printf 'hello world\n' | ./reverse -w
```

输出：

```text
world hello
```

按整行逆序：

```bash
printf 'first line\nsecond line\n' | ./reverse -l
```

输出：

```text
second line
first line
```

同时按行和词逆序：

```bash
printf 'a b\nc d\n' | ./reverse -lw
```

输出：

```text
d c
b a
```

读取文件：

```bash
./reverse -w /path/to/file.txt
```

如果不提供文件，`reverse` 会从标准输入读取。

### 4.3 实现说明

| 功能 | 对应文件 |
| --- | --- |
| `-l`、`-w`、`-lw` 参数解析 | `main/reverse_main.cpp` |
| 单词逆序处理 | `src/reverse.cpp` |
| 接口声明 | `include/reverse.h` |

`reverse_main.cpp` 先根据 `-w` 调用 `reverse_words()` 反转每行中的单词，再根据 `-l` 反转整行顺序，从而覆盖按行、按词、同时按行和词逆序三种方式。

## 5. fs_auditor 使用方法

### 5.1 基本用法

```bash
./fs_auditor <目录路径> <报告文件名>
```

例如：

```bash
./fs_auditor /home/nixos/workspace/C-Demo/Linux/work_2 audit_report.txt
```

查看报告：

```bash
cat audit_report.txt
```

### 5.2 参数说明

| 参数 | 作用 |
| --- | --- |
| `-e EXT` | 只统计指定扩展名的普通文件 |
| `-j N` | 使用 N 个线程并行扫描目录 |
| `-h` | 显示帮助信息 |

### 5.3 示例

只统计 `.cpp` 文件：

```bash
./fs_auditor -e cpp /home/nixos/workspace/C-Demo/Linux/work_2 cpp_report.txt
```

使用 4 个线程扫描：

```bash
./fs_auditor -j 4 /home/nixos/workspace/C-Demo/Linux/work_2 audit_report.txt
```

组合使用：

```bash
./fs_auditor -e cpp -j 4 /home/nixos/workspace/C-Demo/Linux/work_2 cpp_report.txt
```

### 5.4 报告内容

报告会包含：

- 目标目录
- 扩展名过滤条件
- 普通文件、目录、符号链接、硬链接数量
- 不可读文件和可执行文件数量
- 最近 7 天修改过的文件数量
- 普通文件总大小
- 最大文件和最小文件
- 每个扫描对象的权限字符串
- 扫描过程中遇到的错误

## 6. 退出码说明

`fs_auditor` 使用以下退出码：

| 退出码 | 含义 |
| --- | --- |
| `0` | 成功 |
| `1` | 参数错误 |
| `2` | 目标目录无法访问 |
| `3` | 报告文件无法创建 |

## 7. 清理

编译生成的二进制文件可以删除：

```bash
make clean
```
