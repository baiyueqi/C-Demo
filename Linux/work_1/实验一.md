## 1. 实验目的

1. 掌握 Linux 常用命令的基本格式、常用参数和帮助文档的使用方法。
2. 掌握输入输出重定向、管道等 Shell 工具。

## 4. 命令基本格式与帮助文档

Linux 命令的基本格式：

```text
命令名 [选项] [参数]
```

- 选项通常以 `-` 或 `--` 开头，例如 `ls -l`、`ls --all`。
- 参数是命令操作的对象，例如 `cp 源文件 目标文件`。
- 多个短选项可以合并，例如 `ls -la`。

常用帮助方式：

```bash
ls --help        # 查看命令简要帮助
man ls           # 查看详细手册页
info ls          # 查看 GNU Info 文档
whatis ls        # 查看命令的一行说明
apropos rename   # 按关键词搜索命令
```

## 5. 输入输出重定向与管道

| 符号 | 作用 | 示例 |
| --- | --- | --- |
| `>` | 将标准输出覆盖写入文件 | `ls -l > list.txt` |
| `>>` | 将标准输出追加到文件 | `grep error app.log >> errors.log` |
| `2>` | 将标准错误重定向到文件 | `make 2> build.err` |
| `2>&1` | 将标准错误合并到标准输出 | `make > build.log 2>&1` |
| `<` | 从文件读取标准输入 | `sort < names.txt` |
| `<<EOF` | Here Document，向命令提供多行输入 | `cat <<EOF` |
| `\|` | 管道，将前一个命令的输出交给后一个命令 | `ps aux \| grep ssh` |

示例：

```bash
find / -name "*.conf" 2>/dev/null
dmesg | grep -i error | tail -n 20
make 2>&1 | tee build.log
```

## 6. vi/vim 编辑器

### 6.1 三种模式

| 模式 | 进入方式 | 作用 |
| --- | --- | --- |
| 命令模式 | 启动 vi 后默认进入，或按 `Esc` 返回 | 移动光标、删除、复制、粘贴、查找 |
| 插入模式 | 在命令模式按 `i`、`a`、`o` 等 | 输入文本 |
| 末行模式 | 在命令模式按 `:` | 保存、退出、查找替换、设置 |

### 6.2 常用操作

| 操作 | 按键 |
| --- | --- |
| 进入插入模式 | `i`（光标前）、`a`（光标后）、`o`（下一行）、`O`（上一行） |
| 返回命令模式 | `Esc` |
| 保存退出 | `:w` 保存、`:q` 退出、`:wq` 保存并退出、`:q!` 不保存退出 |
| 查找 | `/关键词` 向下查找、`?关键词` 向上查找、`n` 下一个、`N` 上一个 |
| 复制 | `yy` 复制当前行，`nyy` 复制 n 行 |
| 剪切/删除 | `dd` 删除当前行，`x` 删除一个字符，`dw` 删除一个单词 |
| 粘贴 | `p` 粘贴到光标后，`P` 粘贴到光标前 |
| 选取 | `v` 进入可视模式，移动光标选择文本，再按 `y` 或 `d` |
| 撤销/重做 | `u` 撤销，`Ctrl+r` 重做 |
| 光标移动 | `h/j/k/l` 左/下/上/右，`0` 行首，`$` 行尾，`gg` 文件首，`G` 文件尾 |

### 7.3 等待特定用户登录

文件：[wait_user_login.sh](./wait_user_login.sh)

功能：每 30 秒使用 `who` 检查一次指定用户是否登录；发现登录后通过终端、`wall` 和 `logger` 发出提示。

```bash
#!/usr/bin/env bash
# 开启严格模式
set -euo pipefail

# 必须至少提供一个用户名，否则提示用法并退出
if [[ $# -lt 1 ]]; then
  echo "用法：$0 <用户名> [检查间隔秒数]" >&2
  exit 2
fi

# 第一个参数是要监控的用户名，第二个参数是检查间隔，默认 30 秒
user=$1
interval=${2:-30}

# 检查间隔必须是非负整数
if [[ ! "$interval" =~ ^[0-9]+$ ]]; then
  echo "错误：检查间隔必须是非负整数。" >&2
  exit 2
fi

echo "开始监控用户 $user，每 $interval 秒检查一次。"

# 持续检查，直到目标用户登录
while true; do
  # 从 who 输出中提取第一列用户名，并精确匹配目标用户
  if who | awk '{print $1}' | grep -qx "$user"; then
    msg="用户 $user 已登录系统（$(date '+%F %T')）"
    # 先输出到当前终端
    echo "$msg"

    # 如果系统存在 wall 命令，则向所有终端广播提示
    if command -v wall >/dev/null 2>&1; then
      echo "$msg" | wall 2>/dev/null || true
    fi

    # 如果系统存在 logger 命令，则把提示写入系统日志
    if command -v logger >/dev/null 2>&1; then
      logger -t wait_user_login "$msg" 2>/dev/null || true
    fi

    # 发现用户登录后退出循环
    break
  fi

  # 等待指定时间后继续下一次检查
  sleep "$interval"
done
```

运行：

```bash

whoami
who

# 用当前登录用户 nixos 作为例子，每 10 秒检查一次
bash wait_user_login.sh nixos 10
```

运行结果示例：

```text

开始监控用户 nixos，每 10 秒检查一次。
用户 nixos 已登录系统（2026-11-06 10:32:xx）
```

### 7.4 找出磁盘占用最大的前 10 个用户并发送警告邮件

文件：[top10_disk_users.sh](./top10_disk_users.sh)

说明：脚本默认扫描 `/home` 下各用户目录的磁盘占用，排序后取前 10 名。若系统安装了 `mail` 命令，则向对应用户发送警告邮件；否则在终端输出提示。可通过环境变量 `HOME_ROOT` 和 `MAIL_CMD` 调整扫描目录和邮件命令。

```bash
#!/usr/bin/env bash
# 开启严格模式
set -euo pipefail

# 允许用第一个参数指定统计前几名，也可通过环境变量调整扫描目录和邮件命令
top_n=${1:-10}
home_root=${HOME_ROOT:-/home}
mail_cmd=${MAIL_CMD:-mail}

# 校验统计数量是否为正整数
if [[ ! "$top_n" =~ ^[0-9]+$ ]]; then
  echo "错误：用户数量必须是正整数。" >&2
  exit 2
fi

# 校验扫描目录是否存在
if [[ ! -d "$home_root" ]]; then
  echo "错误：目录不存在：$home_root" >&2
  exit 1
fi

# 统计每个一级用户目录的磁盘占用，并输出“大小(KB) 用户名”
report=$(
  # 遍历扫描目录下的一级子目录
  for user_dir in "$home_root"/*/; do
    # 跳过不是目录的项
    [[ -d "$user_dir" ]] || continue
    # 提取目录名作为用户名
    user=$(basename "$user_dir")
    # 使用 du 统计该用户目录占用的磁盘空间，单位是 KB
    size_kb=$(du -sk "$user_dir" 2>/dev/null | awk '{print $1}')
    # 统计失败时按 0 KB 处理
    printf '%s %s\n' "${size_kb:-0}" "$user"
  done | sort -nr | head -n "$top_n" || true
)

# 如果没有可统计的用户目录，则直接结束
if [[ -z "$report" ]]; then
  echo "没有可统计的用户目录。"
  exit 0
fi

echo "磁盘占用最大的前 $top_n 个用户："
# 将结果整理成“用户名 大小 KB”的可读表格
echo "$report" | awk '{printf "%-16s %s KB\n", $2, $1}'

# 逐行处理前 N 名用户，准备并发送磁盘空间警告
echo "$report" | while read -r size_kb user; do
  body="警告：用户 $user 的家目录当前占用磁盘空间约 $size_kb KB，请及时清理。"

  # 若系统存在指定邮件命令则发送邮件，否则仅在终端提示
  if command -v "$mail_cmd" >/dev/null 2>&1; then
    printf '%s\n' "$body" | "$mail_cmd" -s "磁盘空间警告" "$user" || true
  else
    echo "mail 命令不可用，未发送邮件给 $user。提示内容：$body"
  fi
done
```

运行：

```bash
bash top10_disk_users.sh
```

运行结果示例：

```text
磁盘占用最大的前 10 个用户：
nixos            30289756 KB
user2            4 KB
user1            4 KB
mail 命令不可用，未发送邮件给 nixos。提示内容：警告：用户 nixos 的家目录当前占用磁盘空间约 30289756 KB，请及时清理。
mail 命令不可用，未发送邮件给 user2。提示内容：警告：用户 user2 的家目录当前占用磁盘空间约 4 KB，请及时清理。
mail 命令不可用，未发送邮件给 user1。提示内容：警告：用户 user1 的家目录当前占用磁盘空间约 4 KB，请及时清理。
```

说明：这里提示 `mail 命令不可用`，是因为脚本通过 `command -v "$mail_cmd"` 检查系统是否安装了 `mail` 命令，而当前实验环境没有安装 `mail` 程序（`MAIL_CMD` 默认为 `mail`）。因此脚本不会发送真实邮件，而是进入 `else` 分支，改为在终端输出警告内容。安装 `mailutils` 或 `mailx` 等邮件程序后，脚本就会尝试调用 `mail` 发送邮件。

## 8. 综合脚本 file_manager.sh

文件：[file_manager.sh](./file_manager.sh)

需求实现：

1. 接收一个目录路径作为参数，不存在则创建。
2. 统计该目录下直接文件数量，不递归子目录。
3. 显示最大的 3 个文件及大小。
4. 将该目录下所有 `.log` 文件合并到 `merged.log`，每段前标注来源文件名。
5. 设置 `merged.log` 权限为 `644`。

```bash
#!/usr/bin/env bash
# 开启严格模式
set -euo pipefail

# 必须且只能提供一个非空目录路径
if [[ $# -ne 1 || -z "$1" ]]; then
  echo "用法：$0 <目录路径>" >&2
  exit 2
fi

dir=$1

# 如果同名路径已经存在但不是目录，则报错退出
if [[ -e "$dir" && ! -d "$dir" ]]; then
  echo "错误：$dir 已存在但不是目录。" >&2
  exit 1
fi

# 目录不存在时创建它
if [[ ! -d "$dir" ]]; then
  mkdir -p "$dir"
  echo "目录不存在，已创建：$dir"
fi

# 统计该目录下的一级文件数量，不递归统计子目录，并排除已生成的 merged.log
file_count=$(find "$dir" -maxdepth 1 -type f ! -name 'merged.log' | wc -l || true)
echo "目录：$dir"
echo "文件数量（不含子目录）：$file_count"

echo "最大的 3 个文件："
# 查找一级目录中最大的 3 个文件，并排除已生成的 merged.log，输出“字节数\t路径”
largest=$(find "$dir" -maxdepth 1 -type f ! -name 'merged.log' -printf '%s\t%p\n' 2>/dev/null | sort -nr | head -n 3 || true)

if [[ -z "$largest" ]]; then
  echo "（没有文件）"
else
  # 逐行读取字节数和路径，并转换为人类可读的大小
  echo "$largest" | while IFS=$'\t' read -r size path; do
    human=$(du -h "$path" 2>/dev/null | awk '{print $1}')
    printf '%s\t%s\n' "${human:-${size}B}" "$path"
  done
fi

# 定义合并日志文件路径，并先清空该文件
merged="$dir/merged.log"
: > "$merged"

# 按文件名顺序逐个追加当前目录下的 .log 文件，并在每段前加上来源标记
while IFS= read -r -d '' logfile; do
  {
    printf '# ===== 来源文件: %s =====\n' "$(basename "$logfile")"
    cat "$logfile"
    printf '\n'
  } >> "$merged"
done < <(find "$dir" -maxdepth 1 -type f -name '*.log' ! -name 'merged.log' -print0 | sort -z)

# 设置合并日志文件权限为 644
chmod 644 "$merged"
echo "已合并 .log 文件到：$merged（权限 644）"
```

## 9. 权限管理要点

`chmod` 权限使用数字表示：

| 权限 | 数值 |
| --- | --- |
| 读 r | 4 |
| 写 w | 2 |
| 执行 x | 1 |

`644` 表示属主可读写（6）、属组只读（4）、其他用户只读（4）。

```bash
chmod 755 script.sh      # 属主 rwx，属组 r-x，其他 r-x
chmod u+x script.sh      # 给属主添加执行权限
chmod 644 merged.log     # 设置合并日志为 644
chown user:group file    # 修改属主和属组
chgrp group file         # 仅修改属组
```
