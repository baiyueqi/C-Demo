# 实验三操作文档

本实验包含六个程序：

- `task1_signal`：信号与文件读写
- `task2_fifo`：命名管道 FIFO 通信
- `tcp_server` / `tcp_client`：TCP 客户端与服务器
- `udp_server` / `udp_client`：UDP 客户端与服务器

## 3. 运行第 1 题：信号与文件读写

```bash
./task1_signal
```

程序会：

1. 父进程创建 `data_from_parent.txt`
2. 父进程写入文本内容
3. 父进程发送 `SIGUSR1` 给子进程
4. 子进程收到信号后读取文件并输出

注意：`data_from_parent.txt` 会生成在当前工作目录。

## 4. 运行第 2 题：命名管道 FIFO

```bash
./task2_fifo
```

程序会使用 `work3_fifo` 命名管道完成父子进程通信。

## 5. TCP 服务器与客户端

### 5.1 启动服务器

```bash
./tcp_server 8888
```

服务器输出：

```text
TCP server listening on port 8888
```

### 5.2 启动客户端

打开另一个终端：

```bash
./tcp_client 127.0.0.1 8888
```

### 5.3 输入命令

```text
TIME
ECHO:hello
FOO
QUIT
```

客户端会显示类似：

```text
2026-11-06 15:54:46
hello
ERR:UNKNOWN COMMAND
BYE
```

## 7. 应用层协议约定

客户端命令以换行符 `\n` 结束。

| 命令 | 服务器响应 |
| --- | --- |
| `TIME` | 当前时间 |
| `ECHO:内容` | 回显内容 |
| `QUIT` | `BYE` |
| 其他命令 | `ERR:UNKNOWN COMMAND` |

## 8. 一键自动展示

需要先启动服务器。

TCP：

```bash
printf 'TIME\nECHO:hello\nFOO\nQUIT\n' | ./tcp_client 127.0.0.1 8888
```

UDP：

```bash
printf 'TIME\nECHO:hello\nFOO\nQUIT\n' | ./udp_client 127.0.0.1 8888
```

## 9. 功能实现位置

### TCP 服务器

文件：[tcp_server.c](/home/nixos/workspace/C-Demo/Linux/work_3/src/tcp_server.c)

- 使用 `SOCK_STREAM`
- `bind()` 绑定端口
- `listen()` 监听
- `accept()` 接收客户端
- `fork()` 支持多客户端并发访问
- `process_command()` 处理命令

### TCP 客户端

文件：[tcp_client.c](/home/nixos/workspace/C-Demo/Linux/work_3/src/tcp_client.c)

- 使用 `SOCK_STREAM`
- `connect()` 连接服务器
- 从标准输入读取命令
- 接收并显示服务器响应
- 输入 `quit` 后退出

### UDP 服务器

文件：[udp_server.c](/home/nixos/workspace/C-Demo/Linux/work_3/src/udp_server.c)

- 使用 `SOCK_DGRAM`
- `bind()` 绑定端口
- `recvfrom()` 循环接收数据报
- `sendto()` 按客户端地址分别响应

### UDP 客户端

文件：[udp_client.c](/home/nixos/workspace/C-Demo/Linux/work_3/src/udp_client.c)

- 使用 `SOCK_DGRAM`
- `sendto()` 发送命令
- `recvfrom()` 接收响应
- 输入 `quit` 后退出
