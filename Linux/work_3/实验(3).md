# 实验（3）进程管理及进程间通信

## 1. 信号与文件读写

编写一个程序，由父进程负责创建一个新的文本文件，并向文件中写入数据，当数据写入完成后，发送 SIGUSR1 信号给它的一个子进程，该子进程读出文件全部内容并显示。

## 2. 命名管道

用命名管道通信的方式实现第 1 题。

本程序使用 `work3_fifo` 作为命名管道，主要流程如下：

- 使用 `mkfifo()` 创建 FIFO；
- 使用 `fork()` 创建父子进程；
- 子进程以 `O_RDONLY` 打开读端；
- 父进程以 `O_WRONLY` 打开写端；
- 父进程写入消息后发送 `SIGUSR1`；
- 子进程收到信号后读取并输出内容；
- 通信结束后删除 FIFO。

关键代码位于 [task2_fifo.c](./src/task2_fifo.c)：

```c
mkfifo(FIFO_PATH, 0666)

// 子进程打开读端
open(FIFO_PATH, O_RDONLY)

// 父进程打开写端
open(FIFO_PATH, O_WRONLY)
```

## 3. 基于 TCP、UDP 协议的 C/S 进程间通信

在 Internet 中，客户端与服务器之间可以通过 TCP 协议实现可靠通信，也可以通过 UDP 协议实现无连接通信。本题要求基于 POSIX socket 套接字接口，分别实现一个基于 TCP 的客户端/服务器程序和一个基于 UDP 的客户端/服务器程序，完成指定的应用层通信功能。

### 功能要求

#### （1）TCP 服务器与客户端

TCP 服务器应满足以下要求：

- 使用 SOCK_STREAM 套接字；
- 绑定指定端口并监听客户端连接；
- 支持多个客户端依次或并发访问；
- 接收客户端发送的命令字符串；
- 根据命令返回对应结果；
- 客户端断开连接后，服务器应能继续服务其他客户端。

TCP 客户端应满足以下要求：

- 使用 SOCK_STREAM 套接字；
- 连接指定服务器 IP 和端口；
- 从标准输入读取用户命令并发送给服务器；
- 接收并显示服务器返回结果；
- 输入 quit 时关闭连接并退出。

#### （2）UDP 服务器与客户端

UDP 服务器应满足以下要求：

- 使用 SOCK_DGRAM 套接字；
- 绑定指定端口；
- 循环接收客户端数据报；
- 根据收到的命令返回结果；
- 能够区分不同客户端地址并分别响应。

UDP 客户端应满足以下要求：

- 使用 SOCK_DGRAM 套接字；
- 向指定服务器 IP 和端口发送命令；
- 接收并显示服务器返回结果；
- 输入 quit 时退出程序。

#### （3）应用层协议约定

客户端发送的命令格式统一为：

```text
CMD:参数
```

服务器需支持至少以下命令：

| 命令 | 说明 |
| --- | --- |
| TIME | 获取服务器当前时间 |
| ECHO:内容 | 回显客户端发送内容 |
| QUIT | 客户端准备结束通信，服务器端返回“BYE” |

对于不支持的命令，服务器应返回：

```text
ERR:UNKNOWN COMMAND
```

所有消息均以换行符 `\n` 作为一条消息结束标志。

#### （6）参考实现框架

TCP 服务器主循环可参考如下结构：

```c
while (1) {
    int connfd = accept(listenfd, (struct sockaddr *)&client_addr, &client_len);
    if (connfd < 0) {
        perror("accept");
        continue;
    }

    pid_t pid = fork();
    if (pid == 0) {
        close(listenfd);
        handle_client(connfd);
        close(connfd);
        exit(0);
    } else {
        close(connfd);
    }
}
```

UDP 服务器主循环可参考如下结构：

```c
while (1) {
    socklen_t client_len = sizeof(client_addr);
    ssize_t n = recvfrom(sockfd, buf, sizeof(buf), 0,
                         (struct sockaddr *)&client_addr, &client_len);
    if (n < 0) {
        perror("recvfrom");
        continue;
    }

    buf[n] = '\0';
    process_command(buf, response);
    sendto(sockfd, response, strlen(response), 0,
           (struct sockaddr *)&client_addr, client_len);
}
```

### 4.3 运行第 1 题

```bash
./task1_signal
```

程序会创建 `data_from_parent.txt`，父进程写入内容，子进程收到 `SIGUSR1` 后读取并显示文件内容。

验证第 1 题：

```bash
./task1_signal
echo $?
ls -l data_from_parent.txt
cat data_from_parent.txt
```

预期结果：

- `echo $?` 输出 `0`；
- `data_from_parent.txt` 存在；
- 文件内容与程序运行输出一致。

### 4.4 运行第 2 题

```bash
./task2_fifo
```

程序使用命名管道 `work3_fifo` 完成父子进程通信。

验证第 2 题：

```bash
./task2_fifo
echo $?
ls -l work3_fifo
```

预期结果：

- `echo $?` 输出 `0`；
- `ls -l work3_fifo` 显示文件不存在，因为程序结束时会自动清理 FIFO。
